# Afzal — Flutter Developer Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — page content
- `style.css` — responsive dark theme styling
- `script.js` — mobile navigation and current year
- `assets/` — profile photo and Lawyer's Café screenshots

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your `afzal-flutter-dev.github.io` repository.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Visit `https://afzal-flutter-dev.github.io/`.
